## Compare carefully

A record is a school/campus **and stage**, not necessarily a unique school. A readable source may still have no extracted year-level amounts. Missing amounts remain unknown, never zero. Some annual amounts already include compulsory or family levies, so adding the levy again could double-count it. Refundable bonds and tuition credits must be kept separate from permanent costs. No complete first-year total, cheapest-school ranking or average is calculated.
